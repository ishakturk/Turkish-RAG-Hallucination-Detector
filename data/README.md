# Data

Small data files committed with the code. Large files (RAGTruth-TR itself, model predictions on the
translated test, trained weights) are not in git: RAGTruth-TR is downloaded from Hugging Face by the
notebooks, and the final model is released on Hugging Face (see the main README).

## Splits of RAGTruth-TR

| File | Content |
|---|---|
| `splits.json` | Row ids (positions in the Hugging Face `train` split of RAGTruth-TR) for `train`, `validation`, `dev`, `test` and their `_clean` versions. Split by source, so the six answers to one source stay together. `meta` records how the split was made (notebook 01). |
| `mwqa_split.json` | Which multi-wiki-qa (`tr`) articles were used for augmentation and which were held out for the native test set. |

## Native Turkish test set

184 answers written directly in Turkish by two LLMs for questions about Turkish Wikipedia and Turkish
law passages, labeled for hallucination (unsupported content) at answer and span level.

| File | Content |
|---|---|
| `native_test.jsonl` | **The test set**: one answer per line (added by notebook 11). |
| `native_predictions.npz` | Character probabilities of all 22 scored runs on the set (notebook 10), for rescoring without a GPU. |
| `native_labeling_blank.csv` | The sheet that was labeled: question, context and answer, shuffled, without generator or question type. |
| `native_reference_labels.csv` | Final answer-level reference labels and where each came from (LLM agreement, adjudication). |
| `native_spans.json` | Gold hallucinated spans (character offsets into the answer). |
| `native_human_sample*.csv/json` | The 50-row human validation sample, its blank sheet and the human labels. |
| `native_labels_claude*.csv`, `native_claude_labels.sha256.json` | The two LLM label passes and the fingerprint committed before the human labeled. |
| `native_adjudication*.csv` | Disagreements between the human and the reference labels, with the decision and a note. |
| `native_review.json` | Review of the rewritten questions (203 reviewed, 30 rejected). |

**`native_test.jsonl` fields:** `id`, `domain` (`wikipedia`, `legal`), `generator` (`qwen`: Qwen3-8B,
`deepseek`: DeepSeek API), `question_type` (`original`, or `partial`: rewritten so that the passages answer
only part of it), `question`, `passages`, `prompt` (the RAGTruth-TR style prompt the answer was generated
from and the detectors read), `answer`, `label` (1 = contains unsupported content), `spans`
(`start`, `end`, `text`).

**How it was built.**
- **Contexts:** 139 from Turkish Wikipedia articles of multi-wiki-qa that were not used for augmentation,
  and 45 from `mtntasci/turkish-legal-rag` (8 laws), at most 1,500 characters each.
- **Questions:** half are the dataset's own questions; half were rewritten by an LLM so that the context
  answers only part of them, and every rewrite was reviewed by hand.
- **Answers:** generated by Qwen3-8B (in Colab) and DeepSeek (API) with the RAGTruth-TR prompt template;
  bare refusals were dropped.
- **Labeling guide:** written before any answer existed. Only the context counts, so a true fact that the
  context does not contain is a hallucination. Partial answers and refusals are not hallucinations when
  everything they say is in the context.
- **Labels:** two independent LLM (Claude) label passes agreed on 178 of 184 rows (κ = 0.91), and the
  author decided the other 6. The author then labeled a stratified random sample of 50 rows without AI help:
  85.7% agreement, Cohen's κ = 0.38, PABAK 0.71. 6 of the 7 disagreements were resolved in favor of the
  LLM label on review. The check is not fully blind, because the author had seen an earlier AI pass.
- **Spans:** proposed by an LLM and checked automatically (each span occurs exactly once in the answer);
  they were not edited row by row.

**Composition:** 47 of 184 answers are hallucinated (26%). Qwen3-8B 44/100, DeepSeek 3/84; partial
questions 38/84, original questions 9/100; Wikipedia 34/139, legal 13/45. The set mostly measures
hallucinations that fill in missing information, and with 184 answers its confidence intervals are wide.
